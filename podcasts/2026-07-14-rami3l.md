# 深入浅出 Rust

## 学习 Rust 有哪些常见的“坑”

- Significant drop
    - 通常是过早或者过晚进行 drop 操作导致
    - 和控制流的交互（Rust 2024 breaking change）
    - 变量名的使用（`let _` vs `let _foo`）
- Borrow checker
    - 滥用 getter/setter
    - Async x 引用（[lifetime capture rules](https://doc.rust-lang.org/nightly/edition-guide/rust-2024/rpit-lifetime-capture.html)）
- FFI：一定要熟悉目标 API 的约定

## Rust 未来的发展方向

- 处理历史负债
    - [Movables](https://rust-lang.github.io/rust-project-goals/2026/move-trait.html) (`Move`, `Destruct`, `Forget`)
    - 标准库的跨版本演进（以 [`std::range::Range`](https://doc.rust-lang.org/std/range/struct.Range.html) 为例）
- 解决开发者痛点
    - 语言方面
        - [Coroutines and their literals](https://doc.rust-lang.org/std/ops/trait.Coroutine.html)
        - Just add `async` (async iter, async drop, etc.)
        - [`impl Trait` in more places](https://github.com/rust-lang/edition-guide/issues/171)
    - 即插即用（`cargo script`）
    - 热加载（`subsecond`）
    - Rustup
        - 预告：Locked Rustup 和 rustup#988
        - 预告：工具链的去重和验证
